# 小小学习家 · Kids Study Planner

## 自动同步

项目根目录现直接关联 GitHub。后台脚本在文件停止变动 20 秒后，运行测试和 JavaScript 语法检查，自动 commit / push，由已有 GitHub Actions 部署网站。只同步项目源码、资源、文档及启动脚本；`.local`、浏览器数据、环境文件和 `.deploy-repo` 不会上传。Git 操作不调用 AI，不消耗模型 token。

双击「启动自动同步.cmd」启动 / 恢复；双击「暂停自动同步.cmd」暂停。日志在 `.local/auto-sync.log`。断网会保留本地提交并每分钟重试，远程分支有冲突时拒绝推送，不会强制覆盖。Git 登录失效需通过 Git Credential Manager 重新登录。请不要手动暂存其他内容；自动同步脚本会提交 Git 暂存区。

本机登录启动项会启动该后台脚本。需要长期暂停时，可在 Windows「启动应用」中禁用 StudySchedule Auto Sync，并使用暂停脚本。

根据 [planner.md](planner.md) 实现的纯 HTML / CSS / JavaScript 学习计划应用，无运行时依赖。

## 本地运行

Windows 推荐直接双击项目根目录的 **`启动学习计划.cmd`**。启动器会自动寻找 Node.js（包括本机 Codex 自带版本）、在后台启动服务，再打开默认浏览器。关闭启动窗口不会停止服务；再次双击会复用正在运行的学习计划服务。如果想放到桌面，可右键启动文件 → 发送到 → 桌面快捷方式。

后台服务仅监听本机 `127.0.0.1:4173`，重启电脑后再次双击启动器即可。若该端口被其他应用占用，启动器会显示错误。启动脚本通过单次进程参数运行，不修改系统的 PowerShell 执行策略。

需要 Node.js 24 或更新版本。在项目目录执行：

```powershell
node scripts/serve.js
```

打开 http://127.0.0.1:4173 。不要直接双击 index.html；ES 模块、IndexedDB 与 Service Worker 需要 HTTP/HTTPS 环境。

执行测试：

```powershell
node --test
```

## 功能

- 语文、数学、英语任务：首页统计、筛选、日期选择、往期待办、未来与暂停计划管理。
- 新增、编辑、确认删除、完成与撤销；历史完成记录可在设置中查看。
- 单次、每天、每周多选、间隔 N 天重复；开始与结束日期、计划时间、预计时长、暂停与恢复。
- 重复系列与日期实例分离；单日覆盖、从指定日期拆分后续计划、删除墓碑及历史完成记录保留。
- IndexedDB 本机持久化、JSON 导出及合并导入。
- GitHub 私有仓库同步、手动与自动触发、网络恢复与页面回到前台触发同步。
- 响应式侧栏 / 手机底部导航，PWA 清单与离线缓存，完成鼓励反馈。

## GitHub Pages 部署

将项目上传到自己的 GitHub 代码仓库，使用 `main` 分支。在 Settings → Pages → Source 中选择 GitHub Actions。仓库附带 `.github/workflows/pages.yml`，推送后自动测试并部署静态文件，支持仓库子路径。

部署工作流仅打包页面和资源，不包含需求文档、测试或本机凭据。本次开发未替用户创建仓库或发布。

## 配置跨设备同步

1. 创建独立的 **私有** 数据仓库（例如 `kids-study-data`），先创建 README 完成初始化。
2. 在 GitHub 创建 fine-grained PAT，限定该数据仓库，只授予 Contents: Read and write。
3. 在应用「设置与同步」填写所有者、仓库名及 Token，点击「保存并测试连接」。每台设备独立配置。
4. 另一台设备打开同一个 Pages 地址，连接同一数据仓库即可同步。首次访问必须联网，离线资源加载成功后再断网使用。

Token 仅存本机 IndexedDB 的独立配置中，不写入源代码、JSON 备份或同步数据。本机凭据仍有设备访问或网页脚本攻击风险，清除 Token 按钮只清除此设备的配置，撤销授权请在 GitHub 上操作。

为避免多个 JSON 文件部分成功产生不一致，云端使用单个 **`data/state.json` 原子快照**，其中 tasks、exceptions、completions 独立管理（替代 PRD 建议的多个数据文件）。同步基于文件 SHA 乐观并发控制，409 / 422 后重新读取并合并，最多尝试三次。API 行为参考 [GitHub 官方 Contents API](https://docs.github.com/en/rest/repos/contents)。

任务和单日覆盖使用记录修订号与本机上次同步基线做三方合并；相同记录并发修改会显示两个版本，要求用户选择，避免静默覆盖。完成记录按任务日期键合并，冲突时采用更新时间较新的状态（设备时钟应准确）。删除使用墓碑记录，避免其他设备恢复已删除计划。同步过程中产生的新本机修改仍会保留。
